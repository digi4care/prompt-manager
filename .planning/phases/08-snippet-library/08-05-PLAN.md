  <files>src/routes/snippets/new/+page.svelte, src/routes/snippets/[id]/edit/+page.svelte</files>
  <action>
Replace existing form markup with SnippetForm component:

**New page (/snippets/new):**
```svelte
<script>
  import SnippetForm from '$lib/components/snippets/snippet-form.svelte';
  import { goto } from '$app/navigation';
  import { showToast } from '$lib/stores/toast';
  
  async function handleSubmit(data) {
    const res = await fetch('/api/snippets', {
      method: 'POST',
      body: JSON.stringify(data)
    });
    if (!res.ok) throw new Error(await res.text());
    const snippet = await res.json();
    showToast('success', 'Snippet created!');
    goto(`/snippets/${snippet.id}`);
  }
</script>

<SnippetForm onSubmit={handleSubmit} isEditMode={false} />
```

**Edit page (/snippets/[id]/edit):**
- Load snippet data in +page.server.ts
- Pass as initialData prop
- After save, show toast and stay on page (don't redirect)
- Update initialData after successful save to reset hasChanges

Both pages should:
- Handle 409 Conflict error → show specific "Title already exists" error
- Handle validation errors → show field-specific errors
- Show toast on success
