  <name>Task 4: Integrate history into prompt detail page</name>
  <files>src/routes/prompts/[id]/+page.svelte</files>
  <action>
Add execution history section to the prompt detail page:

1. Import ExecutionHistory component
2. Add state for selected log: `let selectedLogId = $state<number | null>(null)`
3. Add state for showing detail: `let showDetail = $state(false)`

4. Add a collapsible/expandable "History" section below the ExecutionPanel:

   ```svelte
   <div class="mt-6">
   	<button
   		class="flex items-center gap-2 text-sm font-medium"
   		onclick={() => (showHistory = !showHistory)}
   	>
   		<History class="h-4 w-4" />
   		Execution History
   		<ChevronDown class={cn('h-4 w-4 transition-transform', showHistory && 'rotate-180')} />
   	</button>

   	{#if showHistory}
   		<div class="mt-4 grid grid-cols-1 gap-4 lg:grid-cols-2">
   			<ExecutionHistory
   				{promptId}
   				onselect={(log) => {
   					selectedLogId = log.id;
   					showDetail = true;
   				}}
   				{selectedLogId}
   			/>
   			{#if showDetail && selectedLogId}
   				<ExecutionLogDetail
   					logId={selectedLogId}
   					{promptId}
   					onclose={() => {
   						showDetail = false;
   						selectedLogId = null;
   					}}
   				/>
   			{/if}
   		</div>
   	{/if}
   </div>
   ```

5. Import History, ChevronDown icons from lucide-svelte

6. Style consistently with existing page layout (use same spacing and container classes)

Place the history section after the ExecutionPanel but before any other sections.
