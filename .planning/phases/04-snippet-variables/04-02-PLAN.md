<behavior>
Replace {{VAR}} placeholders with escaped values. Prevent injection by escaping { and } in user input.

Cases:

- resolveVariables("Hello {{NAME}}", {NAME: "World"}) -> "Hello World"
- resolveVariables("{{A}} {{B}}", {A: "X", B: "Y"}) -> "X Y"
- resolveVariables("{{NAME}}", {}) -> {content: "{{NAME}}", missingVariables: ["NAME"]}
- resolveVariables("{{NAME}}", {NAME: "{{INJECT}}"}) -> "content shows literal {{INJECT}}" (escaped)
- resolveVariables("{{NAME}}", {NAME: "value"}, [{name: "NAME", required: true}]) -> missingVariables: [] if value provided
- resolveVariables("{{NAME}}", {}, [{name: "NAME", required: true}]) -> missingVariables: ["NAME"]
  </behavior>
  <implementation>

1. Add escapeVariableValue() that escapes { -> \{ and } -> \}
2. Add ResolveResult interface with content, missingVariables, hasErrors
3. Implement resolveVariables(template, values, definitions?):
   - Extract all variable names from template
   - Check for missing required variables (from definitions)
   - Replace each {{VAR}} with escaped value or keep placeholder if missing
   - Return result with missing variable list

/**
 * Escape {{ and }} in user-provided values to prevent injection
 * Mustache-style security: prevent users from creating new placeholders
 */
export function escapeVariableValue(value: string): string {
	return value.replace(/\{/g, '\\{').replace(/\}/g, '\\}');
}
```

This is a simple but critical security function. It ensures that if a user enters `{{MALICIOUS}}` as a variable value, it won't be interpreted as a new placeholder in the output.

export interface ResolveResult {
	content: string;
	missingVariables: string[];
	hasErrors: boolean;
}

export interface VariableValues {
	[name: string]: string;
}

/**
 * Replace {{VAR}} placeholders with values
 * - Escapes {{ and }} in values to prevent injection
 * - Returns list of missing required variables
 * - Keeps escaped placeholders for missing vars in output
 */
export function resolveVariables(
	template: string,
	values: VariableValues,
	definitions?: SnippetVariable[]
): ResolveResult {
	const missingVariables: string[] = [];

	// Build set of required variable names from definitions
	const requiredVars = new Set(
		definitions?.filter((v) => v.required !== false).map((v) => v.name) || []
	);

	// Collect all variable names in template
	const templateVars = new Set<string>();
	const regex = new RegExp(VARIABLE_REGEX.source, 'g');
	let match: RegExpExecArray | null;

	while ((match = regex.exec(template)) !== null) {
		templateVars.add(match[1]);
	}

	// Check for missing required variables
	for (const varName of templateVars) {
		if (requiredVars.has(varName) && !(varName in values)) {
			missingVariables.push(varName);
		}
	}

	// Replace variables (escape values for security)
	let resolved = template;
	for (const [name, value] of Object.entries(values)) {
		const escaped = escapeVariableValue(value);
		const varRegex = new RegExp(`{{\\s*${name}\\s*}}`, 'g');
		resolved = resolved.replace(varRegex, escaped);
	}

	return {
		content: resolved,
		missingVariables,
		hasErrors: missingVariables.length > 0
	};
}
```

The function:

1. Identifies required variables from definitions
2. Extracts all variable names from template
3. Tracks which required variables are missing
4. Replaces provided values with escaping for security
5. Returns structured result with content and error info
