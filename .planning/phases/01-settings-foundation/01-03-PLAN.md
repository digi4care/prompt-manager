  <name>Task 3: Create council-repeater component</name>
  <files>src/lib/components/admin/function-settings/council-repeater.svelte</files>
  <action>
Create council repeater following user decision: min 2 agents, auto new row, duplicates allowed.

**Props**:
- `agents: CouncilAgent[]` (bindable, array with stable IDs)
- `error: Record<string, string>` (bindable)

**CouncilAgent interface**:
```typescript
interface CouncilAgent {
  id: string; // Client-side stable ID
  modelId: string;
  temperature: number;
  maxTokens: number;
  promptLinkId?: number;
}
```

**Features**:
1. **Minimum 2 agents**:
   - Start with 2 empty agent rows
   - Cannot delete below 2

2. **Auto new row**:
   - When last row has a model selected, add new empty row
   - Use $effect to watch for this condition

3. **Allow duplicates**:
   - Same model can be added multiple times
   - Each agent has independent temperature setting

4. **Row actions**:
   - Add button (always visible at bottom)
   - Delete button (only if > 2 agents)

5. **Each row contains**:
   - Model dropdown (same as model-picker-row)
   - Temperature input (0-2, default 0.5)
   - Max Tokens input (default 8192)
   - Prompt link dropdown
   - Delete button (if > 2)

**Implementation pattern**:
```svelte
<script lang="ts">
  let agents = $state<CouncilAgent[]>([
    { id: crypto.randomUUID(), modelId: '', temperature: 0.5, maxTokens: 8192 },
    { id: crypto.randomUUID(), modelId: '', temperature: 0.5, maxTokens: 8192 }
  ]);

  // Auto-add row when last has model
  $effect(() => {
    const lastAgent = agents[agents.length - 1];
    if (lastAgent?.modelId) {
      agents = [...agents, { id: crypto.randomUUID(), modelId: '', temperature: 0.5, maxTokens: 8192 }];
    }
  });

  function addAgent(): void { ... }
  function removeAgent(id: string): void { ... }
</script>

<tbody>
  <tr class="bg-muted/50">
    <td colspan="6" class="font-semibold">Council Agents</td>
  </tr>
  {#each agents as agent, index (agent.id)}
    <tr>
      <td class="pl-8">Agent {index + 1}</td>
      <!-- Model, Temperature, MaxTokens, Prompt columns -->
      <td>
        {#if agents.length > 2}
          <Button variant="ghost" size="sm" onclick={() => removeAgent(agent.id)}>Remove</Button>
        {/if}
      </td>
    </tr>
  {/each}
  <tr>
    <td colspan="6">
      <Button variant="outline" size="sm" onclick={addAgent}>Add Agent</Button>
    </td>
  </tr>
</tbody>
```
