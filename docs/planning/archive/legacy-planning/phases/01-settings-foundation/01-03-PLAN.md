Fix JSON.parse errors when database contains comma-separated strings instead of JSON arrays.

**Problem**: Database stores tags as "code,review,analysis" but code expects ["code","review","analysis"]

**Solution**: Safe parsing helper:

```typescript
function safeParseJsonArray(value: string | null): string[] {
	if (!value) return [];
	try {
		const parsed = JSON.parse(value);
		return Array.isArray(parsed) ? parsed : [parsed];
	} catch {
		// Fallback: comma-separated string
		return value
			.split(',')
			.map((s) => s.trim())
			.filter(Boolean);
	}
}

// Usage:
const tags = safeParseJsonArray(prompt.tags);
const providers = safeParseJsonArray(prompt.llm_providers);
```
