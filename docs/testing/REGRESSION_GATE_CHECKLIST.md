# Regression Gate Checklist

## Pre-Implementation

- [x] Mode decision recorded.
- [x] Analysis strategy exists.
- [x] Analysis todo exists.
- [x] Universe coverage accounted.

## Pre-Apply

- [x] Omission audit has no unresolved critical blockers.
- [ ] Implementation plan exists.
- [ ] Build todo exists.
- [ ] Matrix + traceability synchronized.
- [ ] Cross-boundary fields in matrix are filled for FE/BE interaction changes.
- [ ] Contract tests exist for changed client/server payloads.
- [ ] E2E interaction tests exist for changed FE/BE flows.

## Validation

- [ ] Required tests pass.
- [ ] No unresolved P0 blockers.
- [ ] Generation report updated.
- [ ] Error mapping validated (`status/code/message`) for interaction changes.
