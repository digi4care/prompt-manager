<task type="auto">
  <name>Add snippet taxonomy tables to schema</name>
  <files>src/lib/server/db/schema.ts</files>
  <action>
Add two new tables to schema.ts:

1. **snippet_categories** table:
   - id (integer, primary key, auto-increment)
   - name (text, unique, not null)
   - description (text, nullable)
   - sort_order (integer, default 0)
   - created_at, updated_at timestamps

2. **snippet_tags** table:
   - id (integer, primary key, auto-increment)  
   - name (text, unique, not null)
   - created_at, updated_at timestamps

3. **snippet_tag_assignments** junction table (many-to-many):
   - snippet_id (foreign key to snippets)
   - tag_id (foreign key to snippet_tags)
   - Composite primary key

4. Modify snippets table:
   - Change category from text to category_id (foreign key to snippet_categories, nullable)
   - Remove tags column (replaced by junction table)

Run `npm run db:push` after schema changes.

Include default seed data:
- Categories: "greetings", "formatting", "prompts", "templates"
- Tags: "variable", "reuse", "common", "advanced"
  </action>
  <verify>npm run db:push succeeds, tables exist in database</verify>
  <done>Schema has snippet_categories, snippet_tags, snippet_tag_assignments tables; snippets.category_id foreign key added</done>
</task>

Same pattern for tags.

**Also add public endpoints for dropdowns:**

- GET /api/snippets/tags → list for dropdown
