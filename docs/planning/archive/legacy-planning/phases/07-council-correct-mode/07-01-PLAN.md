<task type="auto">
  <name>Task 2: Create council-correct.service.ts orchestrator</name>
  <files>src/lib/server/services/council-correct.service.ts</files>
  <action>
Create council correct orchestrator service that sequences producer → reviewer → fixer steps.

1. Types to export:

```typescript
export type CouncilState = 'idle' | 'producing' | 'reviewing' | 'fixing' | 'complete' | 'error';
export type CouncilStep = 'producer' | 'reviewer' | 'fixer';

export interface CouncilEvent {
	type:
		| 'step_start'
		| 'step_delta'
		| 'step_complete'
		| 'round_complete'
		| 'council_complete'
		| 'error';
	step?: CouncilStep;
	round: number;
	data: unknown;
}

export interface CouncilRun {
	id: number;
	promptId: number;
	inputContent: string;
	currentRound: number;
	maxRounds: number;
	state: CouncilState;
	steps: CouncilStepResult[];
	finalOutput?: string;
	createdAt: Date;
	updatedAt: Date;
}

export interface CouncilStepResult {
	step: CouncilStep;
	round: number;
	input: string;
	output: string;
	issues?: string[]; // For reviewer step only
	model: { providerId: string; modelId: string; displayName: string };
	usage: { inputTokens: number; outputTokens: number; totalTokens: number };
	duration: { ms: number; seconds: number };
	executedAt: Date;
}
```

2. Main export - async generator for streaming:

```typescript
export async function* executeCouncilCorrect(options: {
  promptId: number;
  content: string;
}): AsyncGenerator<CouncilEvent, CouncilRun, unknown>
```

3. Implementation pattern:
   - Create council run record in database (state='idle')
   - Loop while currentRound <= MAX_ROUNDS (3):
     a. PRODUCER step: streamPromptExecution({ functionType: 'executor', content: currentInput })
     - Yield step_start, yield each step_delta, yield step_complete
     - Capture producer output
       b. REVIEWER step: streamPromptExecution({ functionType: 'judge', content: buildReviewerPrompt(producerOutput) })
     - Yield step_start, yield each step_delta, yield step_complete
     - Parse reviewer output for pass/fail status and issues
       c. If reviewer passed OR currentRound >= MAX_ROUNDS:
     - Yield council_complete with finalOutput
     - Update state='complete', return CouncilRun
       d. FIXER step: streamPromptExecution({ functionType: 'improve', content: buildFixerPrompt(producerOutput, issues) })
     - Yield step_start, yield each step_delta, yield step_complete
     - Fixer output becomes input for next round
       e. Increment currentRound, yield round_complete
   - Persist each step result to database (update steps JSON)

4. Helper functions:
   - buildReviewerPrompt(producerOutput: string): string - Prompts for JSON {status: 'pass'|'fail', issues: string[]}
   - buildFixerPrompt(producerOutput: string, issues: string[]): string - Prompts to fix specific issues
   - parseReviewerOutput(content: string): { status: 'pass' | 'fail'; issues: string[] } - Extract JSON with fallback regex

5. Error handling:
   - Wrap each step in try/catch
   - On error: yield error event, update state='error', persist to DB

6. Import existing services:
   - streamPromptExecution from './streaming.service'
   - resolveFunctionSettings from './settings-cascade.service'
   - db from '../db/client'
   - councilRuns from '../db/schema'

Do NOT use executePrompt() - use streamPromptExecution() for real-time streaming. Aggregate deltas into complete output for each step.
</action>
