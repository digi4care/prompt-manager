# 01 -- Personas

## Primary Persona: Admin / Prompt Engineer
**Name:** Alex
**Role:** Technical user who creates, tests, and manages prompts
**Goals:**
- Create prompts with predictable execution outcomes
- Version and iterate on prompts with diff visualization
- Execute prompts with settings-first model resolution
- Use AI-powered improvement loops and judging

**Constraints:**
- Needs deterministic, auditable execution
- Settings cascade must be transparent
- Must trust the model selection logic

## Secondary Persona: Reviewer
**Name:** Riley
**Role:** Reviews prompt quality via rubric-based judging
**Goals:**
- Evaluate prompt outputs with consistent criteria
- Provide structured feedback for improvement

## System Persona: Developer
**Name:** Devin
**Role:** Maintains and extends the prompt management system
**Goals:**
- Understand the architecture and conventions
- Add new features without breaking existing flows
- Debug issues with clear error codes
