  <name>Task 1: Install marked.js and create markdown-renderer.svelte</name>
  <files>src/lib/components/prompts/markdown-renderer.svelte</files>
  <action>
First, install marked.js:
```bash
npm install marked
```

Then create the markdown renderer component:

1. **Props interface**:

   ```typescript
   interface Props {
   	content: string;
   	class?: string;
   }
   ```

2. **Configure marked for security**:
   - Import `{ marked }` from 'marked'
   - Set options: `{ breaks: true, gfm: true }`
   - GFM enables GitHub Flavored Markdown (tables, task lists)

3. **Sanitization approach**:
   - By default, marked doesn't sanitize HTML
   - Use DOMPurify OR implement basic HTML escaping for raw HTML blocks
   - For simplicity: escape HTML entities in content before parsing:
     ```typescript
     function escapeHtml(text: string): string {
     	return text.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;');
     }
     ```
   - Apply to content, then parse with marked

4. **Derived HTML**:

   ```typescript
   let html = $derived.by(() => {
   	try {
   		const escaped = escapeHtml(content);
   		return marked.parse(escaped) as string;
   	} catch {
   		return `<pre>${escapeHtml(content)}</pre>`;
   	}
   });
   ```

5. **Render with innerHTML**:

   ```svelte
   <div
   	class="markdown-content prose prose-sm max-w-none dark:prose-invert {className}"
   	innerHTML={html}
   ></div>
   ```

6. **Styling with Tailwind prose**:
   - Use `prose` classes for typography
   - Add custom styles for code blocks:
     ```svelte
     <style>
     	:global(.markdown-content pre) {
     		@apply overflow-x-auto rounded-lg bg-muted p-4;
     	}
     	:global(.markdown-content code) {
     		@apply font-mono text-sm;
     	}
     	:global(.markdown-content :not(pre) > code) {
     		@apply rounded bg-muted px-1.5 py-0.5;
     	}
     </style>
     ```

7. **Error handling**:
   - Wrap in try/catch
   - Fallback to escaped pre-formatted text on parse error

DO NOT:

- Render untrusted HTML without escaping
- Allow script tags or event handlers in output
- Forget dark mode support (dark:prose-invert)

<task type="auto">
  <name>Task 2: Create execution-result.svelte with metadata bar</name>
  <files>src/lib/components/prompts/execution-result.svelte</files>
  <action>
Create the result display component with metadata bar and copy action:

1. **Props interface**:

   ```typescript
   interface Props {
   	result: {
   		content: string;
   		model: { displayName: string; providerId: string; modelId: string };
   		usage: { inputTokens: number; outputTokens: number; totalTokens: number };
   		duration: { ms: number; seconds: number };
   		source: 'run' | 'prompt' | 'default';
   	};
   	oncopy?: () => void;
   	class?: string;
   }
   ```

2. **Source label mapping**:

   ```typescript
   const sourceLabels = {
   	run: 'Run Override',
   	prompt: 'Prompt Setting',
   	default: 'Global Default'
   };
   ```

3. **Copy functionality**:

   ```typescript
   let copySuccess = $state(false);

   async function handleCopy() {
   	await navigator.clipboard.writeText(result.content);
   	copySuccess = true;
   	oncopy?.();
   	setTimeout(() => {
   		copySuccess = false;
   	}, 2000);
   }
   ```

4. **Layout structure**:

   ```svelte
   <div class="space-y-4">
   	<!-- Metadata bar -->
   	<div class="flex items-center justify-between text-sm text-muted-foreground">
   		<div class="flex items-center gap-4">
   			<span class="font-medium">{result.model.displayName}</span>
   			<span>·</span>
   			<span>{result.usage.totalTokens} tokens</span>
   			<span>·</span>
   			<span>{result.duration.seconds}s</span>
   		</div>
   		<span class="rounded bg-muted px-2 py-1 text-xs">
   			{sourceLabels[result.source]}
   		</span>
   	</div>

   	<!-- Content -->
   	<div class="rounded-lg border p-4">
   		<MarkdownRenderer content={result.content} />
   	</div>

   	<!-- Actions -->
   	<div class="flex justify-end">
   		<Button variant="outline" size="sm" onclick={handleCopy}>
   			{#if copySuccess}Copied!{:else}Copy{/if}
   		</Button>
   	</div>
   </div>
   ```

5. **Import dependencies**:
   - Button from `$lib/components/ui/button`
   - MarkdownRenderer from `./markdown-renderer.svelte`
   - cn from `$lib/utils` for class merging

6. **Responsive considerations**:
   - Metadata bar wraps on small screens
   - Token count shows total, not input/output separately (to save space)

DO NOT:

- Show raw content without markdown rendering
- Forget the source badge (critical for transparency)
- Make copy button primary (outline is appropriate)
