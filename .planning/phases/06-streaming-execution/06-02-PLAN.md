<task type="auto">
  <name>Create ExecutionStream component</name>
  <files>src/lib/components/prompts/execution-stream.svelte</files>
  <action>
Create a Svelte 5 component that consumes SSE streams using sveltekit-sse `source()`:

Props interface:

```typescript
interface Props {
	promptId: number;
	content: string;
	overrides?: RunOverrides;
	oncomplete?: (result: { content: string; usage?: Usage; duration?: Duration }) => void;
	onerror?: (error: { message: string }) => void;
}
```

Component requirements:

1. **State management** with Svelte 5 runes:
   - `connection` - store source() return value
   - `isStreaming` - boolean state
   - `streamContent` - accumulated text
   - `error` - error message if any

2. **startStream() function**:
   - Reset state (streamContent = '', error = null)
   - Create connection via `source('/api/prompts/${promptId}/stream', { method: 'POST', body: JSON.stringify({ content, overrides }) })`
   - Handle `open`, `close`, `error` callbacks
   - Use `connection.select('delta')` with $effect to append deltas
   - Use `connection.select('complete')` with $effect to call oncomplete
   - Use `connection.select('error')` with $effect to call onerror

3. **Reconnection logic** in close callback:
   - Track reconnectAttempts
   - If !isLocal and reconnectAttempts < 3, reconnect with exponential backoff
   - Otherwise set isStreaming = false

4. **abortStream() function**:
   - Call `connection.close()`
   - Set isStreaming = false
   - Clear connection

5. **UI structure**:
   - Streaming content display with prose styling and cursor animation
   - Stop button (Square icon) when streaming
   - Execute button (Play icon) when idle

6. **Export from index.ts**

Use existing patterns from execution-panel.svelte:

- Same icons: Play, Loader2, Square from lucide-svelte
- Same Button component
- Reuse ExecutionResult component for final display (passed via oncomplete callback)

CRITICAL: Use $effect for reactive subscription to select() stores, not direct assignment in callbacks.
</action>
