  <name>Task 1: Create execution.service.ts with SDK integration</name>
  <files>src/lib/server/services/execution.service.ts</files>
  <action>
Create the execution service that wraps OpenCode SDK session.chat() with:

1. **ExecutionError class** - Custom error class extending Error with:
   - `statusCode: number` (HTTP status)
   - `code: string` (machine-readable code like 'AUTH_FAILED', 'RATE_LIMITED')
   - `userMessage: string` (user-friendly message)
   - `recoveryHint?: string` (actionable suggestion)
   - Static `fromSDKError(error: unknown)` method that maps SDK errors:
     - `Opencode.AuthenticationError` → 401, 'AUTH_FAILED', 'API authentication failed'
     - `Opencode.RateLimitError` → 429, 'RATE_LIMITED', 'Too many requests'
     - `Opencode.APIConnectionError` → 503, 'NO_CONNECTION', 'Cannot connect to AI service'
     - `Opencode.APIConnectionTimeoutError` → 504, 'TIMEOUT', 'Request took too long'
     - Generic → 500, 'UNKNOWN', 'An unexpected error occurred'

2. **ExecutionResult interface**:

   ```typescript
   export interface ExecutionResult {
   	content: string;
   	model: {
   		providerId: string;
   		modelId: string;
   		displayName: string;
   	};
   	usage: {
   		inputTokens: number;
   		outputTokens: number;
   		totalTokens: number;
   	};
   	duration: {
   		ms: number;
   		seconds: number;
   	};
   	source: 'run' | 'prompt' | 'default';
   }
   ```

3. **executePrompt function**:
   - Accept `{ promptId, content, functionType, overrides }` (functionType defaults to 'executor')
   - Track start time with Date.now()
   - Call `resolveFunctionSettings()` from settings-cascade.service with promptId and runOverrides
   - Parse model ID format `providerId/modelId` (split on '/')
   - Get OpenCode client via `getOpencodeClient()`
   - Create ephemeral session with `client.session.create()`
   - Use try/finally to ensure session deletion:
     ```typescript
     const session = await client.session.create();
     try {
     	const response = await client.session.chat(session.id, {
     		parts: [{ type: 'text', text: content }]
     	});
     	// extract content, build result
     } finally {
     	await client.session.delete(session.id);
     }
     ```
   - Extract text content from response.parts
   - Calculate duration from start time
   - Return ExecutionResult with all metadata

4. **Import from SDK error classes**:
   ```typescript
   import Opencode from '@opencode-ai/sdk';
   // Use Opencode.AuthenticationError, Opencode.RateLimitError, etc.
   ```

DO NOT:

- Keep sessions open after execution (MUST delete in finally block)
- Return raw SDK errors to callers
- Forget to track duration for success and error cases

<task type="auto">
  <name>Task 2: Create execute API endpoint</name>
  <files>src/routes/api/prompts/[id]/execute/+server.ts</files>
  <action>
Create the POST endpoint for prompt execution:

1. **Request validation with Zod**:

   ```typescript
   const executeRequestSchema = z.object({
   	content: z.string().min(1, 'Content is required').max(100000, 'Content too long'),
   	versionId: z.number().optional(),
   	overrides: z
   		.object({
   			modelId: z.string().optional(),
   			temperature: z.number().min(0).max(2).optional(),
   			maxTokens: z.number().int().min(1).max(1000000).optional()
   		})
   		.optional()
   });
   ```

2. **Authentication**:
   - Use `authenticateRequest(event)` from `$lib/server/auth/jwt`
   - Returns user object or throws 401

3. **Path parameter**:
   - Parse `event.params.id` as promptId
   - Return 400 if not a valid number

4. **Request handling**:
   - Parse body with `event.request.json()`
   - Validate with `executeRequestSchema.safeParse()`
   - Return 400 with `{ message, errors }` on validation failure

5. **Execution**:
   - Call `executePrompt({ promptId, content, functionType: 'executor', overrides })`
   - Return `json(result)` on success (200)

6. **Error handling**:
   - Catch `ExecutionError` instances
   - Return appropriate HTTP status with structured error:
     ```typescript
     throw error(
     	err.statusCode,
     	JSON.stringify({
     		message: err.userMessage,
     		code: err.code,
     		recovery: err.recoveryHint
     	})
     );
     ```
   - Catch unknown errors, log with console.error, return 500

Follow existing API patterns from Phase 1 endpoints (function-defaults, prompt-settings).
