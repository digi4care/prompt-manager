**Problem:**

- Tags stored as `"code,review,analysis"` instead of `'["code","review","analysis"]'`
- Providers stored as `"all"` instead of `'["all"]'`

**Solution - Safe parse helper:**

```typescript
function safeParseArray(value: string | null): string[] {
	if (!value) return [];

	// Already JSON array
	if (value.startsWith('[')) {
		try {
			return JSON.parse(value);
		} catch {
			return [];
		}
	}

	// Comma-separated string
	return value
		.split(',')
		.map((s) => s.trim())
		.filter(Boolean);
}
```
