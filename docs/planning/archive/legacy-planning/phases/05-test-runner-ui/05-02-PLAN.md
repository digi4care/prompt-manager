<task type="auto">
  <name>Task 1: Integrate TestRunnerPanel into edit page sidebar</name>
  <files>src/routes/prompts/[id]/edit/+page.svelte</files>
  <action>
    Add TestRunnerPanel to the edit page sidebar as a collapsible section.

    Changes required:

    1. Add imports at top of script:
    ```typescript
    import { TestRunnerPanel } from '$lib/components/prompts';
    import { parseSnippetFrontmatter, type SnippetVariable } from '$lib/opencode/frontmatter';
    import { ChevronDown, ChevronUp, FlaskConical } from 'lucide-svelte';
    ```

    2. Add state for test runner visibility:
    ```typescript
    let showTestRunner = $state(false);
    ```

    3. Add derived variable extraction from frontmatter:
    ```typescript
    let parsedFrontmatter = $derived(parseSnippetFrontmatter(frontmatterYaml));
    let snippetVariables = $derived(parsedFrontmatter.variables);
    ```

    4. Add TestRunnerPanel section in sidebar (after PromptFrontmatterEditor, before Current Version Info):
    ```svelte
    <!-- Test Runner Section -->
    <div class="rounded-lg border bg-card p-4">
      <button
        type="button"
        onclick={() => (showTestRunner = !showTestRunner)}
        class="flex w-full items-center justify-between text-left"
      >
        <div class="flex items-center gap-2">
          <FlaskConical class="h-4 w-4 text-muted-foreground" />
          <h3 class="text-sm font-semibold">Test Runner</h3>
        </div>
        {#if showTestRunner}
          <ChevronUp class="h-4 w-4 text-muted-foreground" />
        {:else}
          <ChevronDown class="h-4 w-4 text-muted-foreground" />
        {/if}
      </button>

      {#if showTestRunner}
        <div class="mt-4">
          <TestRunnerPanel
            promptId={data.prompt.id}
            template={content}
            variables={snippetVariables}
            functionType="executor"
          />
        </div>
      {/if}
    </div>
    ```

    Placement: Add this section in the sidebar `<aside>` element, between PromptFrontmatterEditor and the Current Version Info section.

    Do NOT:
    - Modify the main editor area
    - Change the save functionality
    - Add persistence for test runner state (in-memory only as per research)

  </action>
