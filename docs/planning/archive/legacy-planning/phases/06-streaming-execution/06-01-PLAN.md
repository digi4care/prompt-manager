  <action>
Create a streaming service that:

1. Exports `StreamingEvent` types: `delta`, `complete`, `error`
2. Exports `streamPromptExecution(options)` async generator that:
   - Subscribes to OpenCode events via `client.event.subscribe()`
   - Creates an ephemeral session
   - Sends the prompt (non-blocking)
   - Yields `{ type: 'delta', delta: string, accumulated: string }` for each message.part.delta event filtered by sessionID
   - Yields `{ type: 'complete', content: string, usage: {...}, duration: {...} }` when session.idle event received
   - Yields `{ type: 'error', message: string }` on session.error
   - Returns cleanup function that deletes the OpenCode session

Key patterns from existing execution.service.ts to follow:

- Use `getOpencodeClient()` for client access
- Use `resolveFunctionSettings()` for model resolution
- Parse model ID format: providerId/modelId
- Track timing with Date.now()

CRITICAL: Filter events by sessionID - OpenCode event.subscribe() is global and emits for ALL sessions. Store sessionID after session.create() and only yield events matching that ID.

RACE CONDITION PREVENTION: Subscribe to events BEFORE creating session to avoid missing early deltas.
</action>

Create POST endpoint using sveltekit-sse `produce()`:

1. Validate request body (content, overrides) with Zod - same schema as /execute endpoint
2. Authenticate with `authenticateWithBetterAuth(event)`
3. Use `produce()` with:
   - `ping: 15000` for heartbeat every 15 seconds
   - `stop()` callback for cleanup logging
   - Return cleanup function to delete session
4. Inside produce, iterate over `streamPromptExecution()` generator:
   - `emit('delta', JSON.stringify(event))` for delta events
   - `emit('complete', JSON.stringify(event))` for completion
   - `emit('error', JSON.stringify(event))` for errors
   - `lock.set(false)` when done to close connection

The endpoint should:

- Accept same request format as /execute (content, overrides)
- Resolve settings through cascade
- Return SSE events named 'delta', 'complete', 'error'

Example produce structure from research:

```typescript
return produce(
  async function start({ emit, lock }) {
    // iterate generator, emit events
    for await (const event of streamPromptExecution(...)) {
      const { error } = emit(event.type, JSON.stringify(event));
      if (error) { lock.set(false); return; }
      if (event.type === 'complete' || event.type === 'error') {
        lock.set(false);
        return;
      }
    }
    return function cleanup() { /* session cleanup */ };
  },
  { ping: 15000, stop() { console.log('Stream stopped'); } }
);
```
